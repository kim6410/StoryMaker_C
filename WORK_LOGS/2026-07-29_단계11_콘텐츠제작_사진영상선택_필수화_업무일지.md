# 2026-07-29 단계11 보완 - 콘텐츠 제작 시 사진/영상 선택 필수화

## 요청 배경

사용자 실사용 테스트 중 발견: "영상 만들기 할때 이미지 업로드를 필수로 넣어야 하는데 없음..ㅎㅎ"

`/content/new`(새 콘텐츠 제작) 화면에 업체 사진·영상 선택 체크박스는 있었으나 "선택" 항목으로만
표시되어 있었고, 서버는 `media_ids`가 비어 있어도 제작을 그대로 진행시켰다.

## 결정 사항

두 가지 범위(1) 화면에서 1장 이상 선택만 막기, 2) 실제 MP4 렌더링이 선택한 사진을
장면 배경으로 사용하도록 파이프라인 자체를 확장 중 사용자에게 직접 확인한 결과
**1번(화면에서 선택 필수화)**을 선택함. 실제 사진을 영상 장면에 합성하는 렌더링
파이프라인 확장은 별도의 큰 작업이며, 기존 그라디언트 장면 계약(단계8)을 건드리지
않기로 한 범위 밖 결정이므로 이번 작업에는 포함하지 않았다. (미완료 항목으로 계속 추적)

## 구현

- `app/main.py` `create_content_job()`
  - 업체 소유 검증 후 `selected_media_ids`가 비어 있으면 `/content/new`로 되돌리고
    한글 오류 메시지(`사진/영상을 1개 이상 선택해 주세요.`)를 붙여 리다이렉트.
  - 주제 미입력 오류 리다이렉트에도 `company_id`를 함께 보존하도록 수정(기존에는
    사진 미선택으로 되돌아갈 때 업체 선택이 초기화되는 부수 문제가 있었음).
- `app/templates/content_new.html`
  - 라벨을 "이번 제작에 참고할 업체 사진·영상 (선택)" → "...(필수, 1개 이상 선택)"으로 변경.
  - 업로드된 사진이 하나도 없는 업체는 안내 문구를 경고색으로 바꾸고 "먼저 사진을
    업로드해야 제작을 시작할 수 있습니다"로 명확화.
  - 업로드된 사진이 없으면 "제작 시작" 버튼을 `disabled` 처리(서버 검증과 별개로
    사용자가 애초에 시도하지 못하도록).
  - 클라이언트 측 JS: 제출 시 체크된 `.media-checkbox`가 0개면 `preventDefault()`로
    막고 "사진을 선택해주세요." 경고를 인라인으로 표시 + 해당 영역으로 스크롤.

## 검증 (포트 8033, 8032/8031 무관섭)

httpx 기반 실제 HTTP E2E:
1. 로그인 → 업체 없음 확인 → `/companies` POST로 테스트 업체 생성(실 라우트 경유,
   DB 직접 조작 없음)
2. `/companies/{id}/media` POST로 1x1 PNG 실제 업로드
3. `media_ids` 없이 `/content/new` POST → `303` → `/content/new?...error=...` 로
   되돌아가고 화면에 "선택해" 오류 문구 노출 확인 (PASS)
4. `/content/new?company_id=...` GET에서 "필수, 1개 이상 선택" 라벨 노출 확인 (PASS)
5. 업로드한 사진 1개를 `media_ids`로 포함해 다시 POST → `303` → `/content/job/{uid}`로
   정상 진행 확인 (PASS)

`scripts/db_selftest.py` 24/24 PASS 재확인(회귀 없음).

테스트에 사용한 임시 스크립트는 검증 후 즉시 삭제, 8033 테스트 서버는 검증 후 종료함.
8032(사용자 실사용 서버)는 이번 작업 중 전혀 건드리지 않았다 — 새 코드가 반영되려면
사용자가 8032를 재시작해야 한다(uvicorn은 코드 변경을 자동 반영하지 않음, 이전에도
동일한 원인으로 두 차례 "기능이 안 보임" 오탐이 있었음).

  E2E 등)
