# 2026-07-29 단계11 보완 - 콘텐츠 제작 화면 직접 업로드 + 업체정보 아코디언

## 요청 배경

"지금 새 콘텐츠 제작 첫 화면에서 이미지 업로드가 있어...?? 없어서 다음 화면으로 못넘어감...."

바로 전 작업(사진 1개 이상 선택 필수화)의 부작용: `/content/new`는 **이미 업체 관리에
업로드된 사진 중에서 고르는** 체크박스만 있었고, 그 화면 자체에는 파일을 새로 올리는
기능이 없었다. 업체에 사진이 하나도 없으면 체크할 대상 자체가 없어 필수 검증에 막혀
다음 화면으로 못 넘어가는 막다른 골목이 생겼다.

이어서 "업체 정보는 어차피 기본값이어서 아코디안 메뉴로 해서 사용자가 필요할때만
펼쳐보이게 해주면 됨" 요청도 같은 화면에 반영.

## 구현

- `app/main.py`
  - `/companies/{id}/media` 업로드 로직을 `_save_company_media_files(company, files)`
    공용 헬퍼로 분리(기존 동작 100% 동일, 저장된 media_id 목록도 함께 반환하도록 확장).
  - `create_content_job()`(`POST /content/new`)에 `new_media_files: list[UploadFile]`
    파라미터 추가. 제출 시 새로 올라온 파일을 먼저 업체 미디어로 저장하고, 그 media_id를
    체크박스로 선택한 기존 media_ids와 합쳐서 "1개 이상" 필수 검증을 통과시킨다. 즉
    기존에 올려둔 사진을 고르거나, 이 화면에서 바로 새로 올리거나 둘 다 가능해졌다.
- `app/templates/content_new.html`
  - `<form>`에 `enctype="multipart/form-data"` 추가(기존 텍스트 필드는 그대로 동작).
  - 사진 선택 영역 아래에 "새 사진·영상 업로드" `<input type="file" multiple>` 추가.
    업체에 기존 사진이 없어도 이제 막다른 골목이 아니라 바로 업로드하면 된다.
  - 제출 버튼의 `disabled`(기존 미디어 0장이면 무조건 비활성) 조건 제거 — 서버가 실제
    선택+업로드 합계로 검증하므로 클라이언트에서 미리 막을 필요가 없어짐.
  - 클라이언트 측 JS 검증도 체크박스뿐 아니라 새 파일 입력에 파일이 있으면 통과하도록 수정.
  - "업체 정보" 섹션을 `<details><summary>업체 정보 (기본값 사용 중 · 펼쳐서 확인)</summary>...`
    로 감싸 기본은 접힌 상태로 표시하고 필요할 때만 펼쳐보게 함(네이티브 HTML accordion,
    추가 JS 불필요).

## 검증 (포트 8033, 8032/8031 무관섭)

- httpx E2E: 사진이 0장인 새 업체를 만들고 `/content/new`에 진입 → 업로드 input 노출,
  제출 버튼 비활성화 아님 확인 → 기존 미디어 체크 없이 새 파일 1장만 업로드해서 제출 →
  `/content/new`로 되돌아가지 않고 `/content/job/{uid}`로 정상 진행 확인(PASS) → 업로드한
  파일이 실제로 업체 미디어로 저장돼 다음 방문 시 체크박스 목록에 나타나는지 확인(PASS).
- 아코디언 마크업(`<details class="accordion">`) 렌더링 확인(PASS).
- `scripts/db_selftest.py` 24/24 PASS 재확인(회귀 없음).
- 테스트 중 실제 Gemini 호출이 몇 차례 실패(`unknown_provider_error`)했다가 동일
  프로젝트로 즉시 재시도하면 성공하는 현상을 반복 관찰함 — 재현 시도 결과 이번 변경과
  무관하게(기존 `generate_channels_for_project` 로직 자체의 응답 검증 단계에서 비결정적
  으로 발생) 매번 재시도 시 성공하므로, 기존에도 있던 AI 응답 검증 관련 산발적 실패로
  판단(이번 커밋의 회귀 아님). 사용자가 반복적으로 겪는다면 별도로 원인 조사 필요.

임시 테스트 스크립트는 검증 후 삭제, 8033은 종료함. 8032는 건드리지 않음(반영하려면
재시작 필요).
