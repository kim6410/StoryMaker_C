정상 키 또는 결제·할당량이 있는 프로젝트 키가 적용되면 코드 변경 없이 다음만 재검증한다.

1. HTTP 200
2. 유효 JSON 응답
3. 스키마 검증 성공
4. DB 상태 `completed`
5. 로그 비밀값 노출 0

정상 키 적용 전에는 같은 키로 반복 호출하지 않는다.
