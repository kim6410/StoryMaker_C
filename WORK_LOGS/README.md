# StoryMaker_C 업무일지 폴더

이 폴더에는 `F:\StoryMaker_C`에서 수행한 작업의 Markdown 업무일지만 저장합니다.

작업을 시작하기 전에는 루트의 `00_READ_FIRST.md`를 먼저 읽습니다.

그다음 이 폴더에서 가장 최근 작성된 업무일지를 확인합니다.

## 파일명 규칙

`YYYY-MM-DD_StoryMaker_C_작업주제_업무일지.md`

예시:

`2026-07-28_StoryMaker_C_초기환경조사_업무일지.md`

## 필수 기록 항목

- 작성일시
- 작업 목적
- 사용자 요청
- 조사한 환경
- 생성한 파일
- 수정한 파일
- 변경하지 않은 기존 영역
- 구현 내용
- 테스트 결과
- PC 화면 확인 결과
- 모바일 화면 확인 결과
- 오류와 해결 내용
- 미완료 항목
- 다음 작업 순서
- 사용자 승인 필요 항목
- Git 상태

확인하지 못한 내용은 추측하지 않고 `미확인`으로 기록합니다.

스크린샷, 임시 테스트 파일, 출력 로그, 진단 덤프는 이 폴더에 저장하지 않습니다.
