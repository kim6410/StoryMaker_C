다음은 완료로 인정하지 않는다.

- 눌러도 아무 반응이 없는 버튼
- `href="#"`만 있는 메뉴

- 관리자 화면에서 숫자만 표시하고 상세 데이터로 이동하지 못하는 기능

# A. 공통 브라우저 실동작 기준

## 3. 모든 메뉴와 버튼 전수 검사

브라우저에서 실제 로그인한 상태로 사용자 메뉴와 관리자 메뉴를 하나씩 전부 클릭한다.

각 메뉴·버튼에 대해 다음을 확인한다.

- 클릭 반응이 즉시 나타나는가
- 올바른 URL 또는 화면으로 이동하는가
- 권한이 없는 사용자가 접근하지 못하는가
- 새로고침 후 같은 상태가 유지되는가
- 뒤로가기·앞으로가기가 정상인가
- 중복 클릭이 중복 작업을 만들지 않는가
- 로딩 중 버튼이 비활성화되는가
- 실패하면 재시도할 수 있는가
- 성공 메시지가 실제 저장 결과와 일치하는가
- 키보드 Enter·Space로 실행 가능한가
- 모바일 터치로 정상 동작하는가

모든 버튼에 실제 이벤트가 연결되어야 한다.

죽은 버튼, 임시 링크, 빈 메뉴는 제거하거나 실제 기능을 연결한다.

## 4. 브라우저 콘솔·네트워크 기준

주요 E2E 시나리오를 실행하면서 다음을 확인한다.

- JavaScript error 0건
- Unhandled Promise rejection 0건
- 실패한 API 요청 0건 또는 사용자에게 정상 처리된 예상 실패만 존재
- 404 정적파일 0건
- 500 응답 0건
- 반복 폴링 폭주 없음
- 동일 API 중복 호출 없음
- 무한 로딩 없음
- CORS 오류 없음
- Range 요청 정상
- CSRF·세션·권한 오류가 사용자 흐름을 깨지 않음

브라우저 개발자도구에서 확인한 콘솔·네트워크 결과를 업무일지에 기록한다.
